# ML-Models — IA táctica del titán enemigo

Modelos `.onnx` de código abierto (Hugging Face) o políticas entrenadas con ML-Agents y exportadas a ONNX,
ejecutados localmente con Unity Sentis. Reglas completas: sección 5 de `CLAUDE.md`.

Por cada modelo, añade aquí:
- Repositorio de origen en Hugging Face y licencia (Apache-2.0 / MIT).
- Forma de los tensores de entrada (observaciones) y salida (movimiento + slot de habilidad 0–3).
- Frecuencia de decisión prevista (Hz).
